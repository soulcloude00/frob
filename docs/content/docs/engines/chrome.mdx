Chrome (and Chromium) is the default browser engine. frob discovers, launches, and manages the Chrome process automatically via the Chrome DevTools Protocol (CDP).

## Binary Discovery

When no `--executable-path` is provided, frob checks the Chrome it downloaded with `frob install` first, then searches the platform locations in this order:

<table>
  <thead>
    <tr><th>Platform</th><th>Locations checked</th></tr>
  </thead>
  <tbody>
    <tr>
      <td>macOS</td>
      <td>
        <code>/Applications/Google Chrome.app</code>,
        <code>/Applications/Google Chrome Canary.app</code>,
        <code>/Applications/Chromium.app</code>,
        <code>/Applications/Brave Browser.app</code>,
        the same apps in <code>~/Applications</code>,
        Puppeteer cache (<code>~/.cache/puppeteer/chrome/</code> or <code>PUPPETEER_CACHE_DIR</code>),
        Playwright cache (<code>~/.cache/ms-playwright</code> or <code>PLAYWRIGHT_BROWSERS_PATH</code>)
      </td>
    </tr>
    <tr>
      <td>Linux</td>
      <td>
        <code>google-chrome</code>,
        <code>google-chrome-stable</code>,
        <code>chromium-browser</code>,
        <code>chromium</code> in PATH,
        Puppeteer cache (<code>~/.cache/puppeteer/chrome/</code> or <code>PUPPETEER_CACHE_DIR</code>),

      </td>
    </tr>

If Chrome is not found, run `frob install` to download Chrome from Chrome for Testing.

## Usage

Chrome is the default engine -- no `--engine` flag is needed:

```bash
frob open example.com
```

To be explicit:

```bash
frob --engine chrome open example.com
```

## Custom Binary

Point to any Chromium-based browser with `--executable-path`:

```bash
frob --executable-path /path/to/chromium open example.com
```

Or via environment variable:

```bash
export FROB_EXECUTABLE_PATH=/path/to/chromium
frob open example.com
```

## Containers and CI

In Docker, CI runners, or other sandboxed environments, Chrome's user namespace sandbox may need to be disabled:

```bash
frob --args "--no-sandbox" open example.com
```

frob automatically adds `--no-sandbox` when it detects a container environment (Docker, Podman, running as root).

Separate args with newlines, or with commas before another flag. Commas inside a value stay with that flag, so list-valued Chrome flags work:

```bash
frob --args "--disable-features=Translate,HttpsUpgrades,--no-sandbox" open example.com
```

Chrome honors only the last `--enable-features` and the last `--disable-features` switch, so frob merges your values into the lists it already passes instead of adding a second switch.

## Memory use

frob launches Chrome so that a session holds no processes it does not use:

- Chrome starts on `about:blank`, not the New Tab page, unless your `--args` include a startup URL or path.
- Chrome's built-in extensions that have background pages are not loaded. Extensions you load with `--extension` are unaffected.
- The spare renderer that Chrome keeps warm for the next cross-site navigation is disabled (`SpareRendererForSitePerProcess`).
- In headless mode, Chrome's own toolbar and omnibox popup are not rendered (`InitialWebUI`, `WebUIOmniboxPopup`). Headed windows keep them.

To turn one of these features back on, name it in `--enable-features`:

```bash
frob --args "--enable-features=SpareRendererForSitePerProcess" open example.com
```
